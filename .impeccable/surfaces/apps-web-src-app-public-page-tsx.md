# 首頁：正在發生的校園生活

範圍：公開首頁，模式 Read。手機使用者應先辨識班聯會、看見真實校園活動，再找到公告與常用服務；不以未經日期排序的相簿宣稱「最新活動」。

方向：七成瑞士編輯式（粗線開章、左對齊、不對稱留白）、二成校園攝影雜誌（真實活動照主導情緒）。開場是編輯式封面：2px 墨色粗線、小型 HCCA 識別、預設單行「新竹高中班聯會」主標（桌機 80px、手機 36–44px）；後台自訂標題、副標沿用正式內容。主標與照片分開，不互相覆蓋。直角活動實照接在文字下方，真實活動日期、標題及「活動紀錄／攝影集」入口集中疊於照片下緣約三分之一的墨色漸層（明暗主題相同），整張影像連入該活動；桌機圖說標題靠左、入口靠右。無日期時省略，不保留已移除的 Latest story 標籤。

手機與桌機皆以自然捲動展開照片：由右下偏移 40px／28px、4° 傾斜回正，再由左右內縮展開至視窗全寬；日期、標題與入口錯開從 opacity 0.8 變為 1。往上捲可還原，不使用 sticky 或額外長捲動區段。視窗高度至少 540px 且 prefers-reduced-motion 為 no-preference 時才延遲載入 GSAP。減少動態偏好與較矮視窗保留完整靜態構圖；沒有活動或所有照片失敗時採緊湊版型，不留下動態空白。

素材來自正式活動設定，活動沿用相簿來源順序；內建迎新相簿優先選 team-games.webp，已設定相簿維持精選優先及照片原有相對順序。圖片失敗先重試原圖及同活動其他實照，最終顯示緊湊狀態；無資料不虛構活動、日期或最新狀態。

「最新消息」箭頭入口可用鍵盤跳至單一可見的公告標題。活動影像的鍵盤焦點以白框及完整清晰的資訊表達。各章節以同一粗線標題開章、內容密度各異：最新消息為 7／5 欄報紙版面（頭條＋短條列＋開放問卷，條列無逐列箭頭）；常用服務為四個大型純文字入口（桌機四欄、手機兩欄）；文章為大圖導讀＋短條目，整則可點；活動商品為 4:5 暖白型錄底、`contain` 完整呈現（手機四件、平板三件、桌機四件）。間距：組內 16–24px、相鄰區塊 48–64px、主題切換 80–128px。共用導覽與頁尾不在本範圍。
