# 法規與公文公開介面

本規範僅適用 `/regulations`、`/documents` 的查詢與閱讀內容。頁首頁尾、導覽、字體、
按鈕與配色均沿用全站，不建立獨立識別區或 hero；不改動其他功能的視覺體系。

## 查詢與閱讀

- `AdministrativeRouteShell` 僅在 `PublicRouteShell` 內限定內容樣式。
  `PublicSiteHeader`、`PublicSiteFooter` 及既有導覽完整共用，不另外製作行政頁首或頁尾。
- 查詢頁使用有標籤的表單、筆數、排序資訊及細線表格。名稱與主旨是主要連結；
  整列可點擊，連結仍可鍵盤操作。手機依序顯示分類／日期、名稱及補充資料。
- 法規查詢可依名稱／全文、類別、公布／廢止狀態篩選，並依類別、名稱或公布日期排序。
  查詢條件保留在網址。公開結果不顯示技術版本及審議狀態。
- 法規全文以連續條文搭配獨立章節目錄，保留既有深層引用、複製連結及縮放功能。
  手機目錄預設收合；章、節、條、項、款、目有固定縮排。
  技術版本移至歷史版本；公布、施行日期分別呈現。
- 公文檢索提供主旨／全文關鍵字、字號前綴、文書類別與發文日期範圍。
  列表呈現真實發文日期、字號與主旨／摘要，筆數只代表已載入數量。
  既有 API 依建檔日期排序，介面如實標示；支援載入更多。
- 公文採可縮放閱讀的 A4 比例版面，桌面保留文書留白，手機改為流動寬度。
  操作列與正文分開；提供既有後端產生的公文 PDF 與 HTML 本文列印。
  PDF 沿用後端登入限制，匿名顯示「登入下載 PDF」；本文仍可匿名列印。
  只呈現原有欄位，不從承辦人或簽核流程推測正式署名，不添加印章。
- 法規主頁依權限提供資料同步與待公布資料查詢；全文保留公布操作。
  公文管理入口併入文件工具列；公文簽核功能保留於文書本文外。

## 排版與資料語意

- 色彩使用既有 `--public-*` 與 `--primary-*` tokens，管理操作使用全站 `btn` 元件樣式。
- 字體直接繼承全站，法規與公文不另外指定明體。標題沿用一般內頁尺寸，正文至少 16px。
  法規行高 1.5，各層級間距分別設定；欄位與表格使用對齊的日期數字。
- 所有主要操作目標至少 44px，具有可見焦點；手機避免橫向溢位。
- 條文總數只計 `article_type === "article"` 且未刪除者。章、節、項、款、目不算「條」。
- 日期依 Asia/Taipei 顯示民國年月日。發文日期只取 `issued_at`，缺漏顯示「未載明」，
  不代入送簽或建檔日期。API 列表以既有 ORM 欄位提供 `issued_at`，無儲存結構變更。
- 公布狀態不推定法規已施行。公開頁不把「已核准」改標為「已發布」，也不將歸檔當成撤銷。
- 新增介面須保留載入、無資料、失敗與重試狀態。列印時隱藏導覽、工具、目錄及補充資訊。

## 變更驗證

依 `docs/AI_WORKFLOW.md` 執行 Web、API 靜態檢查、契約檢查與相關回歸。
實際瀏覽器需覆蓋桌面／手機、檢索與清除、無結果／失敗重試、目錄與引用、縮放及列印。
API 的實際資料庫驗證須使用本機 PostgreSQL 測試資料庫；不得以畫面或型別通過代替。

## 雲端法規與閱讀層級

法規來源由主頁的「資料同步」管理，保留自動抓取、解析、沿革快照與公布。
不提供網頁起草、修正案、送審、核定、凍結或人工編輯；舊入口導回查詢或全文，對應寫入 API 已撤除。
既有歷史資料與資料庫欄位保留，不因取消操作流程而刪除原始紀錄。

正文行高 1.5；條間距 0.875em、項間距 0.375em、款間距 0.1875em、目間距 0.125em。
章節前間距 1.5em；子項使用連續縮排與懸掛條號，避免每一目都被操作按鈕撐高。
公文公開與登入後的詳情共用同一正式文書元件，公文簽核操作另行展開，不插入文書本文。
