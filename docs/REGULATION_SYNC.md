# 議會法規來源同步

來源：[議會自治法規資料夾](https://drive.google.com/drive/folders/1DUxeDy7MeN0c_CoeLfd0S7oRWKr6oGkw)。
本功能由各組織具有 `regulation:admin` 的管理員設定，不會自行替所有組織啟用。

## 操作

法規頁 →「法規來源同步」→ 選組織 → 儲存來源及每日／每週／僅手動頻率。
「立即對照並同步」把要求持久化，Celery Beat 每分鐘掃描；離開頁面不會取消要求。
排程以最後一次檢查後 24 小時／7 日計算；畫面時間以 Asia/Taipei 顯示。
逐檔顯示新增、更新、一致、略過或待處理，以及最近一次完整成功時間。

啟用前，部署 API、Web、worker、Beat 的同一版本並套用
`20261113110000` migration。API 與 worker 需設定 `GOOGLE_DRIVE_API_KEY`，
對應 Google Cloud 專案須啟用 Drive API，金鑰限制於 Drive API。
金鑰放在伺服器安全設定，不要貼進聊天、前端環境變數或版本庫。
來源必須允許公開讀取；登入系統使用的 Google OAuth 設定不等於 Drive 讀取金鑰。
僅設定金鑰不會替既有組織自動新增同步來源。

## 更新規則

- 唯讀 Drive v3 API：逐層列出子目錄、完整處理分頁與共用雲端硬碟參數。
  不處理「提案」目錄、暫存檔與以 `!!` 開頭的說明文件；捷徑不跨越來源邊界。
- 支援 Word、文字型 PDF 與原生 Google Docs（匯出 Word）；每檔最多 10 MB，
  最多 100 個資料夾／500 份法規，清單不完整就中止，不將部分清單當成成功。
- 同名文件先看立法沿革；有現行文件時不採已廢止資料夾的舊稿。
  沿革日期相同時優先 Word，避免 PDF 斷行把正文中的引用誤認為新條文。
- 比對同組織、同名法規的結構、正文與沿革。忽略 Markdown 清單符號等呈現差異；
  一致不建立新版本，來源較舊或缺少必要日期時保留系統新版。
- 支援「第四之一條」「第四條之一」「第 4-1 條」及全形／零寬空白；統一儲存為 `4-1`。
- 更新保留可對應條文的 ID、lineage 與修訂快照；移除節點軟刪除，沒有來源檔不推定廢止。
  凍結法規不覆寫，已廢止法規不自動恢復生效。不把同步時間當成廢止日期。
- 重複條號、同名多筆或解析異常列為待處理；單份失敗透過 savepoint 隔離。
  來源檔已連結別筆法規或改名時停止自動建檔，要求人工確認。
- PostgreSQL 列鎖防止同來源同時更新。任務執行前重查設定者的組織權限；權限失效就停止。
  同步交易提交後清除公開法規與儀表板快取。

## 驗證範圍

- 使用本機可丟棄 PostgreSQL 16／Redis，法規解析、同步、權限與既有法規回歸 135 項通過。
- 空 DB 完整 Alembic upgrade 與 `alembic check` 通過；不是以 SQLite 代替 migration 驗證。
- API 靜態檢查、額外 5 個新模組 mypy、Celery consumer 拓撲、契約重建比對。
- Web 型別、812 項 Vitest（137 檔）、coverage 與 production build 通過；lint 保留 8 項既有警告。
  桌面 1440×1000、手機 390×844
  使用本機 production build 及明確 API fixtures 驗證面板，未測正式 OAuth／Drive 金鑰連線。
- GitNexus 完整重建後，變更分析包含 159 個符號、10 條流程，HIGH，`partial=false`、
  `truncated=false`。影響集中於法規解析／更新及列表，已跑對應回歸；索引本身仍有動態派發
  與流程採樣限制，不能以缺少連線宣稱無影響。設定／文件的圖譜缺口以引用、格式與實跑補驗。

## UI 設計與驗收

這是既有法規頁的 Operate（操作）情境擴充，沿用現有色彩 tokens、卡片、輸入欄位與按鈕。
「法規來源同步」以可展開面板逐步揭露設定，依組織 → 來源／頻率 → 儲存與同步操作 →
逐檔結果排列；桌面並列來源與頻率，手機改為單欄。狀態與錯誤使用文字及語意提示，
來源或頻率尚未儲存時停用同步，並提示先儲存設定。

以本機 production build 與 API fixtures 實測桌面 1440×1000、手機 390×844，
涵蓋每週選項、未儲存時禁用同步，以及 Tab 移動焦點、Enter 儲存。
本次獨立設計複核僅針對控制項至少 44px 與 `--primary-text` 文字對比兩項修正，
verdict 為 pass、兩項 resolved、ship；不代表其他介面或正式 Drive 連線已驗收。
畫面留存在本機 `output/playwright/regulation-sync-desktop.png` 與
`output/playwright/regulation-sync-mobile.png`，未納入版本庫。
